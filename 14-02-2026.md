**Solution Description:** `ORDER BY` sorts the result set in ascending or descending order.

## 2. Read Lock

**Problem Statement:** Which of the following is the query to apply Read Lock on table **Employees** in DBMS?

**Options:**

* **`LOCK TABLE Employees READ;`** (Correct)
* `LOCK TABLE Employees READ|WRITE;`
* `LOCK TABLE Employees PRIORITY READ;`
* `LOCK TABLE Employees READ ONLY;`

**Solution Description:** READ LOCK allows a user to only read the data from a table. The syntax for READ LOCK is `LOCK TABLES T_name READ`.

## 3. Data Fragmentation

**Problem Statement:** Some of the columns of a relation are at different sites in which of the following techniques in SQL?

**Options:**

* Data Replication
* Horizontal Partitioning
* **Vertical Partitioning** (Correct)
* Horizontal and Vertical Partitioning

**Solution Description:** To partition the data there are two techniques:

1. **Vertical Partitioning:** In this, we partition the given data vertically i.e. column-wise. So, if we are provided with table students with attributes student id, name, courseid, address, we can store this data by distributing it among servers where we store studentid, name is one server, courseid in another and address in the third one.
2. **Horizontal Partitioning:** In this, we partition the given data horizontally i.e. row-wise. So, have chunks of a certain size of data stored at different servers.

## 4. Data Abstraction Principles

**Problem Statement:** What is meant by data abstraction and independence in a DBMS?

**Options:**

* **Data is separated from the application logic, allowing changes without affecting applications** (Correct)
* Data is physically stored in the same format as applications require
* Application logic cannot be changed without modifying the data structure
* Data is made accessible only to a specific group of users

**Solution Description:** Data abstraction and independence ensure that the underlying data structure can be changed without impacting the application programs, offering flexibility and ease of maintenance.
