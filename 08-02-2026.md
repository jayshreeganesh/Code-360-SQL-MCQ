## **Quiz Summary: DBMS Fundamentals**

### **1. SQL SELECT Statement**

* **Problem Statement:** What does the SQL SELECT statement do?
* **Options:**
* Deletes data
* Inserts data
* **Retrieves data** (Correct)
* Updates data


* **Solution Description:** SELECT is used to retrieve data from a database.

---

### **2. Relationship 1**

* **Problem Statement:** In DBMS, a many-to-many relationship between two entities usually results in how many tables?
* **Options:**
* ONE
* TWO
* **THREE** (Correct)
* FOUR


* **Solution Description:** A many-to-many relationship between two entities usually results in Three tables (two for the entities and one junction/bridge table).

---

### **3. Key Relationship**

* **Problem Statement:** In DBMS, a primary key with the help of foreign key creates a parent-child relationship between the tables that connect them.
* **Options:**
* **True** (Correct)
* False


* **Solution Description:** A primary key of a relation is linked with the foreign key so that the referential constraint is set up between the two relations; hence it creates a parent-child relationship between the tables that connects them.

---

### **4. Concurrency Control**

* **Problem Statement:** A transaction can proceed only after the concurrency control manager _________ the lock to the transaction.
* **Options:**
* **Grants** (Correct)
* Requests
* Allocates
* None of the mentioned


* **Solution Description:** A transaction can proceed only after the concurrency control manager grants the lock to the transaction.

---

### **5. Unary Operation**

* **Problem Statement:** Which is a unary operation in database:
* **Options:**
* Selection operation
* Primitive operation
* Projection operation
* **Generalized selection** (Correct)


* **Solution Description:** Generalization Selection takes only one argument for operation.

> *Note: While technically both Selection and Projection are unary operations in Relational Algebra, "Generalized Selection" was the specific answer required for this query context.*
