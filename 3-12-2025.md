# Code360 Problem of the Day – DBMS MCQs

## 1. Acid Property

**Problem statement**  
The “all-or-none” property is commonly referred to as ______.

**Options**

- Isolation  
- Durability  
- **Atomicity** ✅  
- None of the mentioned  

**Explanation**  
The all-or-none policy is commonly referred to as atomicity; it ensures that work is either fully completed or not done at all, with no intermediate state.

## 2. SQL DROP Command

**Problem statement**  
What does the `DROP` command do in SQL?

**Options**

- Deletes data  
- Modifies data  
- **Deletes a table or database** ✅  
- Joins tables  

**Explanation**  
The `DROP` command removes an entire table or database permanently.

---

## 3. ER Diagram

**Problem statement**  
Which of the following is **not true** for ER Diagram in DBMS?

**Options**

- ER Diagram is a visual representation for ER model  
- ER diagrams have three components: entities, relationships and attributes  
- **ER diagram is not a high level data model diagram** ✅  
- All of the above  

**Explanation**  
An ER diagram is actually a high‑level data model diagram that helps in visualizing and designing database components.

---

## 4. ER Mapping

**Problem statement**  
Match the ER diagram components to their representation in the relational model:

- a. Entity  
- b. Attribute  
- c. Relationship between entities  

Relational model elements:

1. Foreign key  
2. Relation  
3. Columns  

**Correct matching**

- a → 2 (Entity → Relation)  
- b → 3 (Attribute → Columns)  
- c → 1 (Relationship between entities → Foreign key)  

**Answer:** `a2 b3 c1` ✅  

**Explanation**  
In ER to relational mapping, entities become relations (tables), attributes become columns (fields), and relationships are represented using foreign keys.

---

## 5. BCNF

**Problem statement**  
In DBMS, a table is in BCNF if it is in 3NF and if every determinant is a ______ key.

**Options**

- Dependent  
- Normal  
- **Candidate** ✅  
- Both Normal and Candidate  

**Explanation**  
A relation is in Boyce–Codd Normal Form (BCNF) when it is in 3NF and every determinant is a candidate key.
