## 1. SQL DISTINCT Keyword
**Problem Statement:**
What does DISTINCT do in SQL?

* Returns all rows
* **Filters duplicate rows** (Correct)
* Sorts the result
* Joins tables

**Solution Description:**
DISTINCT removes duplicate rows in the result set.

## 3. Data Abstraction
**Problem Statement:**
Which of the following data models describes the database at the highest level in DBMS?

* **Conceptual data model** (Correct)
* Physical data model
* Network data model
* Hierarchical data model

**Solution Description:**
A Conceptual Data Model describes and conveys high-level relationships between concepts/entities. In simpler words, it helps an organization see their data — and the relationships between distinct data.

## 4. Storage Structure
**Problem Statement:**
Which of the following model tells how data will be on the disk?

* **Physical data model** (Correct)
* Creational data model
* Conceptual data model
* Representational data model

**Solution Description:**
Physical Data Model represents the physical structure of the database which includes planning of how the data will be organised, stored on the disk and various access methods available for it.

## 5. Normal form
**Problem Statement:**
Every constraint on the table is a logical consequence of the table's in DBMS.

* Fourth normal form
* Fifth normal form
* **Domain/key normal form** (Correct)
* None of the Mentioned

**Solution Description:**
A relation is in domain-key normal form (DK/NF) if every constraint on the relation is a logical consequence of the definition of keys and domains.
