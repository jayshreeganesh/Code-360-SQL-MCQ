## 2. Hashing Techniques Comparison

**Problem Statement:** What is an advantage of dynamic hashing over static hashing?

* **Options:**
* It is simpler to implement for predictable data sizes.
* **It avoids overflow buckets by adjusting the number of buckets dynamically.** (Correct)
* It uses fewer resources for data retrieval operations.
* It is ideal for datasets that remain constant in size.


* **Solution Description:** Dynamic hashing expands or contracts the number of buckets as needed, redistributing data to avoid overflow issues. This makes it more efficient for systems with unpredictable or growing datasets.

## 4. Deadlock in Databases

**Problem Statement:** What is a deadlock in the context of database transactions?

* **Options:**
* A situation where a transaction is terminated due to insufficient resources.
* **A state where multiple transactions are waiting for each other to release resources, causing a circular wait.** (Correct)
* A condition where a transaction fails to acquire a lock due to high contention.
* A scenario where transactions complete successfully but with inconsistent data.


* **Solution Description:** A deadlock occurs when two or more transactions hold resources and simultaneously request resources held by each other, creating a circular wait that prevents any transaction from proceeding.

* **Options:**
* The entries in the second-level index.
* **The raw data blocks in the database.** (Correct)
* The entries in the third-level index.

* **Solution Description:** The first-level index contains references (pointers) to the blocks of raw data in the database table. These entries enable faster access to the actual data.
