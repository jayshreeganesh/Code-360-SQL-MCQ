## 2. Incremental vs Full Backup
**Problem Statement:** How does an incremental backup differ from a full backup?

* **Options:**
    * It includes a copy of all data and configurations.
    * **It captures only the changes made since the last backup.** (Correct)
    * It requires more storage space than a full backup.
    * It can only be performed once a week.

**Solution Description:**

| Component | Representation |
| :--- | :--- |

| c. Relationship between entities | 3. Columns |

* **Options:**
    * a1 b2 c3
    * **a2 b3 c1** (Correct)
    * a2 b1 c3

**Solution Description:**
An entity in ER diagram is represented by a relation or a table in relational model, similarly attributes of an entity are denoted by columns or fields of the table. Relationships between entities are shown by using foreign keys in relational models.
