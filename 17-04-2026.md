## 3. Index Types
**Problem Statement:** Primary index is further divided into dense index and sparse index, which of the following is true about both?

* [**x**] **Dense index is not space friendly.**
* [ ] Sparse index is not space friendly.
* [ ] Sparse index is faster than Dense index.
* [ ] a and c

**Solution Description:**
The difference between dense index and sparse index is shown below:

| Feature | Dense Index | Sparse Index |
| :--- | :--- | :--- |
| **Space** | Space taken for the index table is large. | Space taken for the index table is smaller. |
| **Time** | Time taken to locate the record is less in comparison. | Time taken to locate the record is more. |
| **Records** | The records in the data file are in specific order and need not be in any kind of cluster or chunk. | The records in the data file are in specific order but the data records are in a cluster or chunk. |

## 4. Data Sharing
**Problem Statement:** What do you mean by Data Sharing in DBMS?

* [**x**] **Same data visible to everyone**
* [ ] Different data for everyone
* [ ] Multiple versions of data
* [ ] Anyone can access data

**Solution Description:**
The act of sharing the same data resource with multiple applications or users is known as data sharing. In the case of DBMS when the same information is visible to everyone, it is called data sharing.
