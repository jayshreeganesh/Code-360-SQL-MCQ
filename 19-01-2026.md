## 4. Procedure Alteration

* **Problem Statement:** Which of the following is a correct command if we have to alter an existing Stored Procedure in MySQL?
* **Options:**
* ALTER PROCEDURE Sp1;
* ALTER PROCEDURE Sp1 ADD PARAMETER OUT w VARCHAR(10);
* ALTER PROCEDURE Sp1 ADD PARAMETER SET VALUE = DEFAULT;
* **Can't alter in mysql, we must drop the procedure and create a new one.** (Correct)


* **Note:** In MySQL, `ALTER PROCEDURE` only allows you to change certain characteristics (like comments or security context), not the body or parameters of the procedure itself.
