## 2. Incremental vs Full Backup

**Problem Statement:** How does an incremental backup differ from a full backup?

* **Options:**
* It includes a copy of all data and configurations.
* **It captures only the changes made since the last backup.** (Correct)
* It requires more storage space than a full backup.
* It can only be performed once a week.


* **Solution Description:** Incremental backups save only the data that has changed since the last full or incremental backup, reducing storage requirements and speeding up the backup process.

## 4. Index Types

**Problem Statement:** Primary index is further divided into dense index and sparse index, which of the following is true about both?

* **Options:**
* **Dense index is not space friendly.** (Correct)
* Sparse index is not space friendly.
* Sparse index is faster than Dense Index.
* a and c


* **Solution Description:** The difference between dense index and sparse index is shown below:

| Feature | Dense Index | Sparse Index |
| --- | --- | --- |
| **Space** | Space taken for the index table is large. | Space taken for the index table is smaller. |
| **Time** | Time taken to locate the record is less in comparison. | Time taken to locate the record is more. |
| **Data File** | Records in data file are in specific order and need not be in clusters. | Records in data file are in specific order but the data records are in a cluster or chunk. |

## 5. ACID Property

**Problem Statement:** The "all-or-none" property is commonly referred to as __________.

* **Options:**
* Isolation
* Durability
* **Atomicity** (Correct)
* None of the mentioned


* **Solution Description:** The all-or-none policy is commonly referred to as atomicity. It ensures that work is either completed or not completed and there are no intermediate stages.
