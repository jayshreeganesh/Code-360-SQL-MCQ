## 1. SQL ORDER BY Clause
**Problem Statement:** What is the purpose of ORDER BY?

* [ ] Join tables

## 2. DBMS Basics
**Problem Statement:** Which of the following is not True:

* [ ] **DB and DBMS are the same** (Selected)
* [ ] Database stores data.
* [ ] DBMS is a software
* [ ] All of the above.
