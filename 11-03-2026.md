## **1. Data Definition Language (DDL)**

**Problem Statement:** Which is a DDL command in SQL?

* [ ] SELECT
* [ ] UPDATE
* [ ] DELETE
* [**x**] **CREATE**

**Solution Description:** `CREATE` is a DDL command used to create tables or databases.

---

## **2. DBMS Facts**

**Problem Statement:** Which of the following is true in DBMS:

* [**x**] **We can have multiple candidate keys**
* [ ] We can have multiple primary keys
* [ ] The value of primary key can be same for 2 tuples
* [ ] Alternate key and primary key are the same.

**Solution Description:** A relation can have multiple candidate keys, out of which one is selected as a primary key and the remaining ones are called alternate keys.

---

## **3. Second Normal Form (2NF)**

**Problem Statement:** Tables in second normal form (2NF):

* [**x**] **Eliminate hidden dependencies**
* [ ] Avoid insertion anomalies
* [ ] Have a composite key
* [ ] Non-key fields depend on key

**Solution Description:** The relation in second normal form is also in first normal form and no partial dependencies on any column in primary key.

---

## **4. Transaction Phase**

**Problem Statement:** In DBMS, a transaction that has not been completed successfully is called ________.

* [ ] Compensating transaction
* [**x**] **Aborted transaction**
* [ ] Active transaction
* [ ] Partially committed transaction

**Solution Description:** An aborted transaction is a state after the transaction has been rolled back and the database has been restored to the state prior to the transaction.

---

## **5. DBMS Data Security**

**Problem Statement:** Which of the following is a key advantage of a DBMS related to data security?

* [ ] Allows unrestricted access to all users
* [**x**] **Ensures consistent data and restricts unauthorized access**
* [ ] Eliminates the need for backup and recovery
* [ ] Stores data in multiple locations for better security

**Solution Description:** A DBMS provides mechanisms to ensure data integrity and restricts unauthorized access through access controls and authentication, which enhances security.
