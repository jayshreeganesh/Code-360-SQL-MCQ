## RDBMS

- Question: RDBMS consists of a collection of?
- Options:
    - Tables
    - Fields
    - Records
    - Keys
- Answer: Tables
- Note: An RDBMS organizes data into tables made of rows (records) and columns (attributes).


## SQL ROLLBACK statement

- Question: What does ROLLBACK do in DBMS?
- Options:
    - Saves changes
    - Reverts changes
    - Joins tables
    - Groups data
- Answer: Reverts changes
- Note: ROLLBACK undoes all changes made during the current transaction.


## 3NF

- Question: In DBMS, third normal form is inadequate in situations where the relation:
- Options:
    - has multiple candidate keys
    - has candidate keys that are composite
    - has overlapped candidate keys
    - None of the above
- Answer: None of the above
- Note: 3NF can handle relations with such key properties; inadequacy arises from other issues.


## Transaction control

- Question: Suppose a savepoint named Spt1 is created. Which SQL command rolls back transactions executed after Spt1?
- Options:
    - RELEASE SAVEPOINT Spt1
    - COMMIT Spt1
    - ROLLBACK TO Spt1
    - ROLLBACK
- Answer: ROLLBACK TO Spt1
- Note: This restores the state to the specified savepoint.


## Recursive relation

- Question: In DBMS, a recursive relationship is a relationship between an entity and ________.
- Options:
    - itself
    - a subtype entity
    - an archetype entity
    - an instance entity
- Answer: itself
- Note: Example is an employee supervising another employee in the same entity set.
