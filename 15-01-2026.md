## 2. TCL Command

**Problem Statement:** Which of the following are TCL commands in DBMS?

* **Options:**
* [ ] UPDATE and TRUNCATE
* [ ] SELECT and INSERT
* [ ] GRANT and REVOKE
* [x] **ROLLBACK and SAVEPOINT**


* **Solution Description:** Transaction control commands manage changes made by DML commands. These SQL commands are used for managing changes affecting the data.

## 4. Clustered Index

**Problem Statement:** Which one is true about the clustered index?

* **Options:**
* [ ] Not linked with table
* [x] **Built on unique key by default**
* [ ] Not built on unique key
* [ ] None of the mentioned


* **Solution Description:** A clustered index is built by default on unique key columns. Nonclustered indexes have a structure separate from the data rows. A nonclustered index contains the nonclustered index key values and each key-value entry has a pointer to the data row that contains the key value.

## 5. Exclusive Mode

**Problem Statement:** In DBMS, if a transaction has obtained a ________ lock, it can both read and write on the item.

* **Options:**
* [ ] Shared mode
* [x] **Exclusive mode**
* [ ] Read only mode
* [ ] Write only mode


* **Solution Description:** If a transaction has obtained an exclusive mode lock, then it can both read and write on the item on which it is operating.
