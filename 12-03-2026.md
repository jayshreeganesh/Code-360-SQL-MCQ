### **3. Null Values & Aggregate Functions**

* **Problem Statement:** In DBMS, which of the following aggregate functions does **not** ignore null values?
* **Selected Option:** **`Count(*)`** (Correct)
* **Solution Description:** `*` selects all values including null; thus, `count(*)` considers null values also.

### **4. Storage Issue**

* **Problem Statement:** What is the same data being saved in multiple locations called?
* **Selected Option:** **Redundancy** (Correct)
* **Solution Description:** Repeating the same data at different locations is called data redundancy. In file-based systems, it is very difficult to keep track of redundancy.

---

### **5. Concurrency Control**

* **Problem Statement:** In File-based systems, it is easy to maintain concurrency control when multiple users are updating the same file.
* **Selected Option:** **False** (Correct)
* **Solution Description:** A concurrency control system should provide safe access to shared information, removing the risk of collisions. In a file system, concurrent updates can cause data integrity problems; hence, concurrency is not easy to achieve.
