## **Problem 2: Transaction Control**

**Problem Statement:**
Suppose we have created a savepoint named Spt1, which of the following commands in SQL can be used to rollback the transactions executed after creating the savepoint:

**Options:**

* RELEASE SAVEPOINT Spt1
* COMMIT Spt1
* **ROLLBACK TO Spt1** (Correct)
* ROLLBACK

**Solution Description:**
ROLLBACK transaction - This TCL commands undo all the changes or restore the current state to any previously saved state. General form: ROLLBACK: This rollback the previously committed command to its initial state ROLLBACK TO savepoint: This undoes the current state and restores it to the savepoint.

## **Problem 4: Primary Key**

**Problem Statement:**
In DBMS, a primary key should be:

**Options:**

* Null
* Not null
* Unique
* **Unique and not Null** (Correct)

**Solution Description:**
A primary key is a unique identifier that helps us to identify each and every tuple uniquely. No two rows have the same value for the primary key Attribute and the primary key cannot be null. The primary key in the table cannot be changed. It is selected out of all the candidate keys by the database admin.
