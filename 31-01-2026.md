## **DBMS Quiz: Problem of the Day**

### **1. JOIN Operations**

* **Problem Statement:** What does an **INNER JOIN** return?
* **Correct Option:** **Matching records from both tables**
* **Solution Description:** INNER JOIN returns rows when there is a match in both tables.

### **2. Functional Dependencies**

* **Problem Statement:** Functional Dependencies are the types of constraints that are based on ______.
* **Correct Option:** **Key**
* **Solution Description:** The key is the basic element needed for the constraints.

### **3. Primary Key**

* **Problem Statement:** In DBMS, a primary key should be:
* **Correct Option:** **Unique and not Null**
* **Solution Description:** A primary key is a unique identifier that helps us to identify each and every tuple uniquely. No two rows have the same value for the primary key attribute and the primary key cannot be null. It is selected out of all the candidate keys by the database admin.

### **4. BCNF (Boyce-Codd Normal Form)**

* **Problem Statement:** In DBMS, a table is in BCNF if it is in 3NF and if every determinant is a ______ key.
* **Correct Option:** **Candidate**
* **Solution Description:** (Implicit) For a functional dependency ,  must be a super key/candidate key.

### **5. Union of Primary Key**

* **Problem Statement:** The union of primary keys of the related entity sets becomes a ______ of the relation.
* **Correct Option:** **Super Key**
* **Note:** In many ER-to-Relational mappings, this union specifically forms the primary key of the relationship set, which by definition is also a super key.
