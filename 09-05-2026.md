## **1. Transaction Phase**

**Problem Statement:**
In DBMS, a transaction that has not been completed successfully is called ________.

**Options:**

* Compensating transaction
* **Aborted transaction** (Correct)
* Active transaction
* Partially committed transaction

**Solution Description:**
An aborted transaction is a state after the transaction has been rolled back and the database has been restored to the state prior to the transaction.

## **3. Deadlock in Databases**

**Problem Statement:**
What is a deadlock in the context of database transactions?

**Options:**

* A situation where a transaction is terminated due to insufficient resources.
* **A state where multiple transactions are waiting for each other to release resources, causing a circular wait.** (Correct)
* A condition where a transaction fails to acquire a lock due to high contention.
* A scenario where transactions complete successfully but with inconsistent data.

**Solution Description:**
A deadlock occurs when two or more transactions hold resources and simultaneously request resources held by each other, creating a circular wait that prevents any transaction from proceeding.

In precedence of set operators, the expression is evaluated from:

**Options:**

* Left to left
* **Left to right** (Correct)
