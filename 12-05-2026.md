## 5. Query (MCQ Problem)

**Problem Statement:**
You are given a table **Employee** which has the following columns: `id`, `FirstName`, `LastName`.
You have to use a query to display all those employees whose first names start with the letter 'R' and end with the letter 'I'. Some queries are given below:

(a) `SELECT * FROM Employee WHERE FirstName LIKE '%RI%';`
(b) `SELECT * FROM Employee WHERE FirstName LIKE 'R%' AND FirstName LIKE '%I';`
(c) `SELECT * FROM Employee WHERE FirstName LIKE 'R' AND 'I';`
(d) `SELECT * FROM Employee WHERE FirstName LIKE 'R%I';`

Choose the most appropriate SQL query from below:

**Options:**

* Only (c)
* Only (b)
* **(b) and (d)** (Correct)
* (b), (c) and (d)
* (a) and (c)
* None of the above

**Solution description:**
The `LIKE` operator is used to search for a specified pattern in a given column. The percent sign (`%`) wildcard, used in conjunction with the `LIKE` operator, represents zero, one, or multiple characters.

* `LIKE 'R%'` finds values that start with 'R'.
* `LIKE '%I'` finds values that end with 'I'.
* `LIKE '%RI%'` finds values that have "RI" in any position.
* `LIKE 'R%I'` finds values that start with "R" and end with "I".

This query is equivalent to: `SELECT * FROM Employee WHERE FirstName LIKE 'R%' AND FirstName LIKE '%I';`
