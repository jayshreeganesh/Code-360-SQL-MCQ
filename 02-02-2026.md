## 5. Schema Mapping (ER to Relational)

**Problem Statement:** Which of the following relational database schemas is a correct representation for the following ER diagram?

* **Options:**
* `Student(Name, Phone no., Course, Roll No., House no., City)`
* **`Student(Name, Phone no., Course, Roll No.) Address(House no., City, Roll no.)`** (Correct)
* `Student(Name, Phone no., Course, Roll No., Address, House no., City, Roll no.)`
* All of the above



### Solution Breakdown:

1. **Strong Entity Sets:** Converted into a relational schema using the entity name.
2. **Attributes:** Simple attributes become columns.
3. **Multi-valued Attributes:** For attributes like **Address** (which is treated here as a multi-valued or complex component requiring its own table), a separate table is created. It must include the Primary Key of the parent entity (**Roll No.**) as a Foreign Key to maintain the link.
