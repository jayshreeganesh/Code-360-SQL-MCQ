## 5. Transitivity Rule
**Problem Statement:**
Every time attribute A appears, it is matched with the same value of attribute B, but not the same value of attribute C. Therefore, it is true that:[cite: 1]

**Options:**
*   **A -> B** (Correct Answer)[cite: 1]
*   A -> C[cite: 1]
*   A -> (B,C)[cite: 1]
*   (B,C) -> A[cite: 1]

**Solution Description:**
Transitivity rule: Same as a transitive rule in algebra, if $a \to b$ holds and $b \to c$ holds then $a \to c$ also holds. $a \to b$ is called as $a$ functionally determines $b$.[cite: 1]
