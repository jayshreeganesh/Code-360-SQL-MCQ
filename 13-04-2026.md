## 2. Type Constraint
**Problem Statement:** In SQL, for an attribute "Adhaar Number" which is defined as integer type, which constraint would be violated if we enter the PAN (has numbers and alphabets) in it?

**Options:**
* [ ] Entity Integrity constraint
* [ ] Key constraint
* [x] **Domain constraint**
* [ ] Referential Integrity constraint

**Solution Description:** The domain integrity constraints restrict the value in the particular attributes. It defines which values should be considered valid for a particular attribute and which values would be invalid. Therefore, if we want to take email as input in an attribute, then we can use domain constraints to ensure that email is valid. In this question, a similar situation is present as the Adhaar number is defined as an integer, which means the values entered in this attribute should contain digits only. On the other hand, the PAN number contains both digits and alphabets. This will result in the violation of domain integrity constraints and show Invalid status to the user.

## 4. Null values
**Problem Statement:** In DBMS, which of the following aggregate functions does not ignore null values?

**Options:**
* [ ] Max(attribute)
* [ ] Count(attribute)
* [ ] Min(attribute)
* [x] **Count(*)**
* [ ] Both ii) and iv)
* [ ] Both i) and iii)

**Solution Description:** `*` selects all values including null, thus, `count(*)` considers null values also.

## 5. DBMS Architecture
**Problem Statement:** In the context of DBMS, if your laptop has an application like MS Access that is fetching data from another system, it is an example of which type of architecture?

**Options:**
* [ ] 1 tier
* [x] **2 tier**
* [ ] 3 tier
* [ ] None of the above.

**Solution Description:** Since in a two-tier architecture, an interface runs on a client, and a data layer gets stored on a server. In the case of MS access also, an interface is running on your laptop which is actually fetching data from some database on another system. Hence it is an example of 2-tier architecture.
