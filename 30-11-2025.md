## Index Components

**Problem statement:**
In DBMS, the index consists of

- [ ] list of keys
- [ ] pointers to the key in the table
- [x] both (a) and (b)
- [ ] none

**Solution description:**
The index is a data structure used for indexing. Indexes contain a few database columns:

1. The first column consists of a search key, which contains a copy of the primary key of the table so that the data access time could be reduced.
2. The second column is the data reference—pointers holding the address of the disk block where the value corresponding to the key is stored.
