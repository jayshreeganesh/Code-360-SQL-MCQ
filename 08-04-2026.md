## 1. Primary Key
**Problem Statement:** What does a Primary Key enforce?

* **Options:**
    * Uniqueness and Null allowed
    * **Uniqueness and Not Null** (Correct)
    * Only Not Null
    * Only Uniqueness

**Solution Description:** The Primary Key ensures each record in the table is unique and cannot be NULL.

## 2. Dependency Rule
**Problem Statement:** The rule which states that addition of same attributes to the right side and left side will results in other valid dependency in DBMS is classified as:

* **Options:**
    * reflexive rule
    * **augmentation rule** (Correct)
    * transitivity Rule
    * Sigma Rule

**Solution Description:** The augmentation rule states that the addition of the same attributes to the right side and the left side will result in another valid dependency. i.e. If $A \to B$ holds, then $AM \to BM$ holds too. 'M' being a set of attributes.

## 3. Relational Matching
**Problem Statement:** Match the components of relational model which are same:

| List A | List B |
| :--- | :--- |
| a. Tuples | 1. Relation |
| b. Column | 2. Field |
| c. Table | 3. Rows/Record |

* **Options:**
    * a2 b1 c3
    * **a3 b2 c1** (Correct)
    * a1 b3 c2
    * a3 b1 c2

**Solution Description:** A Tuples in the Relational model is represented by a row, also known as records. Similarly, columns are denoted by fields of the table also called attributes. The table is similar to relation in the relational model.

## 4. Query Language
**Problem Statement:** In DBMS, Relational algebra is:

* **Options:**
    * Data Definition Language
    * Meta Language
    * **Procedural query language** (Correct)

**Solution Description:** Relational algebra in DBMS is a procedural query language that uses a set of operations (like selection, projection, union, etc.) to retrieve and manipulate data from relational databases. It serves as the foundation for SQL and provides a formal way of describing how to fetch data based on specified conditions.

## 5. Subqueries-1
**Problem Statement:** Suppose a user has 3 queries Q1, Q2 and Q3. These queries are written in a way i.e. Q1(Q2(Q3)). Which SQL query will be executed first?

* **Options:**
    * Q1
    * Q2
    * **Q3** (Correct)
    * All are updated at the same time

**Solution Description:** Subqueries is a way of using queries within a particular query. It is accomplished using the parenthesis. The inner query is always executed first, followed by the execution of the outer query. Inner query results in a single value or set of values as an output. In the above example, Q3 is the innermost query, so it should be executed first.
