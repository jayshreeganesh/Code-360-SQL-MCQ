## 1. SQL View

**Problem Statement:**
What is a view in SQL?

**Options:**

* A temporary table
* **A virtual table** (Correct)
* A data type

**Solution Description:**
A view is a virtual table based on a SQL query.

## 3. Session Storage

**Problem Statement:**
Which of the following databases is ideal for being used for User's session data retrieval?

**Options:**

* Columnar NoSQL database
* Graph based NoSQL database
* **Key-value NoSQL database** (Correct)
* Document based NoSQL database

**Solution Description:**
**Explanation:** Key-value stores are ideal for storing and retrieving session data at high speeds. The unique Id generated by cookies acts as a key while the other information such as user profiles act as a value.

## 5. Key Relationship

**Problem Statement:**
In DBMS, a primary key with the help of foreign key creates a parent child relationship between the tables that connect them.

**Options:**

* **True** (Correct)
* False

**Solution Description:**
A primary key of a relation is linked with the foreign key, so that the referential constraint is set up between the two relations; hence it creates a parent-child relationship between the tables that connects them.
