## **1. SQL TRUNCATE Command**
* **Problem Statement:** What does the `TRUNCATE` command do?
* **Correct Option:** `Removes all rows`
* **Solution Description:** `TRUNCATE` removes all rows from a table but retains the table structure.

## **2. BCNF (Boyce-Codd Normal Form)**
* **Problem Statement:** In DBMS, a table is in BCNF if it is in 3NF and if every determinant is a __________ key.
* **Correct Option:** `Candidate`
* **Logic:** For a functional dependency $X \rightarrow Y$ to be in BCNF, $X$ must be a superkey (or candidate key).

## **3. Functional Query (LIKE Operator)**
* **Problem Statement:** What is the meaning of `LIKE '%0%0%'` in SQL?
* **Correct Option:** `Feature has two 0's anywhere`
* **Solution Description:** The `LIKE` operator is used in a `WHERE` clause to search for a specified pattern in a column. The `%` wildcard matches any number of characters.

## **4. Book Schema (Degree of Relation)**
* **Problem Statement:** For the given relation **Book**, what is the degree?

| Book_name | Book_code | Book_Price | Author_name | Publish_date |
| :--- | :--- | :--- | :--- | :--- |
| Physics-1 | 011 | 180 | Dr. Raj Nag | 21-03-1996 |
| Chemistry-1 | 021 | 200 | Dr. Kiran Sethi | 25-2-2001 |
| Maths-1 | 031 | 175 | Vipul Sen | 1-6-2006 |

* **Correct Option:** `5`
* **Solution Description:** In the relational model, **degree** refers to the number of attributes (columns) present in the relation.

## **5. Aggregate (Subquery)**
* **Problem Statement:** Find all the tuples having a temperature greater than 'Paris' in SQL.
* **Correct Option:** ```sql
  SELECT * FROM weather WHERE temperature > (SELECT temperature FROM weather WHERE city = 'Paris')
  ```
* **Solution Description:** A subquery—also referred to as an inner query or inner select—is a `SELECT` statement embedded within a data manipulation language (DML) statement or nested within another subquery.
