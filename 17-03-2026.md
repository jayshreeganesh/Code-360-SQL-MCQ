## 3. Index Types
**Problem Statement:** Primary index is further divided into dense index and sparse index, which of the following is true about both?

* [x] **Dense index is not space friendly.**
* [ ] Sparse index is not space friendly.
* [ ] Sparse index is faster than Dense index.
* [ ] a and c

> **Solution description:** The difference between dense index and sparse index is shown below:

| Feature | Dense Index | Sparse Index |
| :--- | :--- | :--- |
| **Space** | Space taken for the index table is large. | Space taken for the index table is smaller. |
| **Time** | Time taken to locate the record is less in comparison. | Time taken to locate the record is more. |
| **Data File Records** | The records in the data file are in specific order and need not be in any kind of cluster or chunk. | The records in the data file are in specific order but the data records are in a cluster or chunk. |

## 4. DBMS Architecture
**Problem Statement:** In the context of DBMS, if your laptop has an application like MS Access that is fetching data from another system, it is an example of which type of architecture?

* [ ] 1 tier
* [x] **2 tier**
* [ ] 3 tier
* [ ] None of the above.

> **Solution description:** Since in a two-tier architecture, an interface runs on a client, and a data layer gets stored on a server. In the case of MS access also, an interface is running on your laptop which is actually fetching data from some database on another system. Hence it is an example of 2-tier architecture.

## 5. Boyce-Codd Normal Form (BCNF)
**Problem Statement:** In DBMS, which one of the following statements about normal forms is FALSE?

* [ ] Lossless, dependency-preserving decomposition into 3 NF is always possible.
* [ ] BCNF is stricter than 3 NF.
* [x] **Lossless, dependency-preserving decomposition into BCNF is always possible.**
* [ ] Any relation with two attributes is BCNF.

> **Solution description:** We say that the decomposition is a lossless decomposition if there is no loss of information by replacing $r(R)$ with two relation schemas $r_1(R_1)$ and $r_2(R_2)$.
