## 3. Transaction mode

**Problem Statement:**
In DBMS, if a transaction has obtained a __________ lock, it can read but cannot write on the item.

**Options:**

* **Shared mode** (Correct)
* Exclusive mode
* Read only mode
* Write only mode

**Solution Description:**
If a transaction Ti has obtained a shared-mode lock (denoted by S) on item Q, then Ti can read, but cannot write, Q.

## 5. Data Fragmentation

**Problem Statement:**
Some of the columns of a relation are at different sites in which of the following techniques in SQL?

**Options:**

* Data Replication
* Horizontal Partitioning
* **Vertical Partitioning** (Correct)
* Horizontal and Vertical Partitioning

**Solution Description:**
To partition the data there are two techniques:

1. **Vertical Partitioning:** In this, we partition the given data vertically i.e. column-wise. So, if we are provided with table students with attributes student id, name, courseid, address, we can store this data by distributing it among servers where we store studentid, name in one server, courseid in another and address in the third one.
2. **Horizontal Partitioning:** In this, we partition the given data horizontally i.e. row-wise. So, have chunks of a certain size of data stored at different servers.
