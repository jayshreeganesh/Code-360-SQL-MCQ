## 3. Data Consistency Advantage
**Problem Statement:** Which of the following is a key advantage of DBMS over file systems regarding data consistency?

* **Options:**
    * File systems use better indexing techniques
    * **DBMS ensures consistent data by managing concurrent access** (Correct)
    * File systems allow multiple users to access data simultaneously

* **Solution Description:** DBMS is designed to handle concurrent data access, ensuring that users receive consistent data, whereas file systems may face issues with concurrent access and data consistency.

## 5. Safe Concurrency
**Problem Statement:** Which of the following concurrency control protocols ensure both conflict serializability and free from deadlock?

* **Options:**
    * **a. Timestamp ordering** (Correct)
    * b. 2 Phase locking
    * c. Both (a) and (b)
    * d. None
* **Solution Description:** 2-phase locking is a concurrency control method that ensures conflict serializability... 2 phase locking may lead to deadlock states... But in timestamp, each transaction is allocated with the time slot. Hence it can't enter a deadlock. So Timestamp ordering ensures both conflict serializability and is free from deadlocks.
