## **Question 1: Primary Key**
**Problem Statement:** What does a Primary Key enforce?

**Options:**
* Uniqueness and Null allowed
* **Uniqueness and Not Null** (Correct)
* Only Not Null
* Only Uniqueness

**Solution Description:** The Primary Key ensures each record in the table is unique and cannot be NULL.

## **Question 2: ALTER Command**
**Problem Statement:** In SQL, ALTER command is a type of:

**Options:**
* Data Manipulation Language
* **Data Definition Language** (Correct)
* Data Control Language
* None of the above

**Solution Description:** ALTER commands modify the structure of the table and hence is a kind of Data Definition Language.

## **Question 3: Data Sharing**
**Problem Statement:** What do you mean by Data Sharing in DBMS?

**Options:**
* **Same data visible to everyone** (Correct)
* Different data for everyone
* Multiple versions of data
* Anyone can access data

**Solution Description:** The act of sharing the same data resource with multiple applications or users is known as data sharing. In the case of DBMS, when the same information is visible to everyone, it is called data sharing.

## **Question 4: One to Many**
**Problem Statement:** In a one-to-many relationship, the entity that is on the one side of the relationship is called a \_\_\_\_\_\_\_\_ entity in DBMS.

**Options:**
* **parent** (Correct)
* child
* instance
* subtype

**Solution Description:** In a one-to-many relationship, the entity that is on the one side of the relationship is called a parent entity in DBMS.

## **Question 5: DBMS Challenges**
**Problem Statement:** Which of the following is a disadvantage of DBMS?

**Options:**
* Ensures fast data retrieval
* Reduces complexity in database management
* **Requires specialized knowledge for setup and maintenance** (Correct)
* Provides automatic crash recovery

**Solution Description:** While DBMS provides many advantages, it also requires specialized knowledge and expertise for setup, management, and ongoing maintenance, which can be a challenge for some organizations.
