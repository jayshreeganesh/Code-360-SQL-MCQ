## Question 2 of 5: Dependency Rule

**Problem Statement**
The rule which states that addition of same attributes to the right side and left side will results in other valid dependency in DBMS is classified as:

**Options**

* [ ] reflexive rule
* [x] **augmentation rule**
* [ ] transitivity Rule
* [ ] Sigma Rule

> **Solution Description**
> The augmentation rule states that the addition of the same attributes to the right side and the left side will result in another valid dependency. If $B$ can be determined from $A$, then adding an attribute to this functional dependency won't change anything. i.e. If $A \rightarrow B$ holds, then $AM \rightarrow BM$ holds too. '$M$' being a set of attributes.

## Question 3 of 5: Concurrency Control

**Problem Statement**
A transaction can proceed only after the concurrency control manager _______ the lock to the transaction.

**Options**

* [x] **Grants**
* [ ] Requests
* [ ] Allocates
* [ ] None of the mentioned

> **Solution Description**

## Question 5 of 5: Recursive Relation

**Problem Statement**
In DBMS, a recursive relationship is a relationship between an entity and _______.

**Options**

* [x] **itself**
* [ ] a subtype entity
* [ ] an archetype entity
* [ ] an instance entity

> **Solution Description**
> In DBMS, a recursive relationship is a relationship between an entity and itself. This occurs when an entity is related to itself in a relationship, such as an employee supervising another employee within the same entity set.
