## Quiz 5: Index Drawbacks

**Problem Statement:**
Which of the following operations does indexing slows down in SQL?

1. DELETE
2. INSERT
3. SELECT
4. READ

**Options:**

* [ ] Only 1,3
* [ ] Only 2,4
* [x] Only 1,2
* [ ] Only 1,2,4

> **Solution Description:**
> Indexing results in the reduction of the speed of execution of write operations in the memory. Major Write operations are INSERT, UPDATE and DELETE operations.
