## **4. Foreign Key**

**Problem Statement:** Which key links two tables in SQL?

**Options:**

* [ ] Primary Key
* [x] **Foreign Key**
* [ ] Candidate Key
* [ ] Unique Key

**Solution Description:**
A foreign key in one table references a primary key in another, establishing relationships between the two.
