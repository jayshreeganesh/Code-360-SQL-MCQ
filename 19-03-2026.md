## 2. Index Ordering
**Problem Statement:** In DBMS, when the records of the main table are sorted on the basis of search key which is also the primary key, and so is the order of the index table, it’s called:

* **Options:**
    * **Primary Indexing** (Correct)
    * Secondary Indexing with key
    * Clustered Indexing
    * Secondary Indexing with non-key
* **Solution Description:** When the indexing is done on the basis of the primary key of the data file it is known as the primary indexing. During the primary indexing, the data file is already ordered to support the primary key. Primary Index is an ordered file whose records are of fixed length with two fields. The primary field of the index replicates the primary key of the information entered in an ordered manner, and therefore the second field of the ordered file contains a pointer that points to the data block where a record containing the keys is available.

## 3. Data Sharing
**Problem Statement:** What do you mean by Data Sharing in DBMS?

* **Options:**
    * **Same data visible to everyone** (Correct)
    * Different data for everyone
    * Multiple versions of data
    * Anyone can access data
* **Solution Description:** The act of sharing the same data resource with multiple applications or users is known as data sharing. In the case of DBMS when the same information is visible to everyone, it is called data sharing.

## 4. Delete & Truncate
**Problem Statement:** Which of the following statements is true in SQL?

* **Options:**
    * **DELETE does not free the space containing the table and TRUNCATE free the space containing the table** (Correct)
    * Both DELETE and TRUNCATE free the space containing the table
    * Both DELETE and TRUNCATE does not free the space containing the table
    * DELETE free the space containing the table and TRUNCATE does not free the space containing the table
* **Solution Description:** The SQL TRUNCATE command is used to delete all the rows from the table and free the space containing the table.

## 5. Data Abstraction Principles
**Problem Statement:** What is meant by data abstraction and independence in a DBMS?

* **Options:**
    * **Data is separated from the application logic, allowing changes without affecting applications** (Correct)
    * Data is physically stored in the same format as applications require
    * Application logic cannot be changed without modifying the data structure
    * Data is made accessible only to a specific group of users
* **Solution Description:** Data abstraction and independence ensure that the underlying data structure can be changed without impacting the application programs, offering flexibility and ease of maintenance.
