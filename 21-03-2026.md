* Sorts data

## 2. DBMS Data Security
**Problem Statement:** Which of the following is a key advantage of a DBMS related to data security?

**Options:**
* Allows unrestricted access to all users
* **Ensures consistent data and restricts unauthorized access** (Correct)
* Eliminates the need for backup and recovery
* Stores data in multiple locations for better security

**Solution Description:** A DBMS provides mechanisms to ensure data integrity and restricts unauthorized access through access controls and authentication, which enhances security.

---

## 3. Data Abstraction Principles
**Problem Statement:** What is meant by data abstraction and independence in a DBMS?

**Options:**
* **Data is separated from the application logic, allowing changes without affecting applications** (Correct)
* Data is physically stored in the same format as applications require
* Application logic cannot be changed without modifying the data structure
* Data is made accessible only to a specific group of users

**Solution Description:** Data abstraction and independence ensure that the underlying data structure can be changed without impacting the application programs, offering flexibility and ease of maintenance.

## 4. FD Relationship
**Problem Statement:** In DBMS, a functional dependency is a relationship between or among __________.

**Options:**
* Entities
* Rows
* **Attributes** (Correct)
* Tables

**Solution Description:** A functional dependency is a relationship between or among Attributes.

---

## 5. Transactions
**Problem Statement:** Collections of operations that form a single logical unit of work are called __________.

**Options:**
* Views
* Networks
* Units
* **Transactions** (Correct)

**Solution Description:** Collections of operations that form a single logical unit of work are called transactions. A database system must ensure the proper execution of the transaction.
