### Problem 1 – Transitivity Rule

**Problem statement**

Every time attribute A appears, it is matched with the same value of attribute B, but not the same value of attribute C. Therefore, it is true that:

- A → B

**Options**

- A → B ✅
- A → C
- A → (B, C)
- (B, C) → A

**Explanation**

If each value of **A** is associated with exactly one value of **B**, then **A functionally determines B**, written as A → B.

### Problem 2 – Subqueries (Operators)-1

**Relation**

Emp(empId, name, gender, salary, deptId)

**Query**

```sql
SELECT name, MIN(salary)
FROM Emp
GROUP BY deptId
HAVING MIN(salary) >
  (SELECT MIN(salary) FROM Employees WHERE deptId = 20);
```

**Correct option**

- It gives the names and minimum salary greater than department 20 of all employees. ✅

**Meaning**

It returns one row per department whose minimum salary is greater than the minimum salary of department 20, showing that department’s name(s) and its minimum salary.
