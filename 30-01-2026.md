## 1. SQL DEFAULT Constraint

**Problem Statement:** What does the DEFAULT constraint do?

* **Options:**
* **Sets a default value** (Correct)
* Ensures unique values
* Checks within a range
* Prevents NULL values


* **Solution Description:** `DEFAULT` sets a default value for a column when no value is specified.

## 2. Database Schema States

**Problem Statement:** The state in a database management system that satisfies the constraints and specified schema structure is classified as:

* **Options:**
* **Valid state** (Correct)
* Extension state
* Intention state
* Attribution state


* **Solution Description:** A database state that follows all integrity constraints is called a valid state.

## 4. Parameter Types

**Problem Statement:** Which procedure parameter enables the caller to pass in a value and get back a value in DBMS?

* **Options:**
* **INOUT** (Correct)
* IN
* OUT
* GOINOUT


* **Solution Description:** The procedure parameter that enables the caller to pass in a value and get back a value in DBMS is the `IN OUT` parameter.
