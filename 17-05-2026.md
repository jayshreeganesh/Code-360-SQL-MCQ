## **Question 1: SQL DEFAULT Constraint**

**Problem Statement:**
What does the `DEFAULT` constraint do?

**Options:**

* (A) **Sets a default value** (Correct)
* (B) Ensures unique values
* (C) Checks within a range
* (D) Prevents NULL values

**Solution Description:**
`DEFAULT` sets a default value for a column when no value is specified.

## **Question 3: ER Mapping**

**Problem Statement:**
Match the ER diagram components to their representation in the relational model:

| ER Component | Relational Model Representation |
| --- | --- |
| a. Entity | 1. Foreign key |
| b. Attribute | 2. Relation |
| c. Relationship between entities | 3. Columns |

**Options:**

* (A) a1 b2 c3
* (B) **a2 b3 c1** (Correct)
* (C) a2 b1 c3
* (D) a3 b1 c2

**Solution Description:**
An entity in an ER diagram is represented by a relation or a table in the relational model. Similarly, attributes of an entity are denoted by columns or fields of the table. Relationships between entities are shown by using foreign keys in relational models.

## **Question 4: TCL Command**

**Problem Statement:**
Which of the following are TCL commands in DBMS?

**Options:**

* (A) UPDATE and TRUNCATE
* (B) SELECT and INSERT
* (C) GRANT and REVOKE
* (D) **ROLLBACK and SAVEPOINT** (Correct)

**Solution Description:**
Transaction control commands manage changes made by DML commands. These SQL commands are used for managing changes affecting the data.

## **Question 5: Locking Protocol**

**Problem Statement:**

**Options:**

* (A) **Locking protocol** (Correct)
* (B) Unlocking protocol
* (C) Granting protocol
* (D) Conflict protocol

**Solution Description:**
The protocol that indicates when a transaction may lock and unlock each of the data items is called a locking protocol. Locking protocols restrict the number of schedules.
