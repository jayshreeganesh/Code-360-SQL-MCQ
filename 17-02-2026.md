## 3. 1NF Requirements

**Problem Statement:** In DBMS, which of the following is **not** required for a table to be in 1NF (First Normal Form)?

* **Options:**
* Attributes to have unique names
* **Free from Transitive dependencies** (Correct)
* Single valued attribute
* Each value in an attribute is of a similar type.



**Solution Description:**
For a relation to justify 1NF, it needs to satisfy 4 basic conditions:

1. Each attribute should contain atomic values.
2. Each value stored in an attribute should be of the same type.
3. All the attributes in a table should have unique names.
4. The order of the data stored in the table doesn't matter.

> **Note:** Being free from transitive dependencies is a requirement for **3NF**, not 1NF.

## 4. DBMS Basics

**Problem Statement:** Which of the following is **not** True:

* **Options:**
* **DB and DBMS are the same** (Correct)
* Database stores data.
* DBMS is a software.
* All of the above.

## 5. Update Ages

**Problem Statement:** A University has the following dataset:

| Id | Name | Age |
| --- | --- | --- |
| 1 | Lawrence | 21 |
| 2 | Aniket | 18 |
| 3 | Carla | 25 |

The dataset was last updated 1 year ago, which means the age of every person in the dataset is 1 year older now. Choose the most appropriate option to update the dataset accordingly.

* **Options:**
* `UPDATE * in University Age=Age+1;`
* **`UPDATE University SET Age = Age + 1;`** (Correct)
* `UPDATE University SET ALL Age=Age+1;`
* We cannot update all the rows at once.



**Solution Description:**
In this question, we need to update the age of every person by one. We can use the `UPDATE` query on the table `University` and increase every element in the `AGE` column by one using the `SET` clause without a `WHERE` condition.
