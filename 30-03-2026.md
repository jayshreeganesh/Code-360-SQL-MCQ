## 2. Acid Property
**Problem Statement:** The "all-or-none" property is commonly referred to as __________.

**Options:**
* [ ] Isolation
* [ ] Durability
* [x] **Atomicity**
* [ ] None of the mentioned

**Solution description:** The all or none policy is commonly referred to as atomicity. It ensures that work is either completed or not completed and there are no intermediate stages.

## 3. Relational Algebra
**Problem Statement:** In the context of DBMS, relational algebra is:

**Options:**
* [ ] Non procedural query language
* [ ] High level language
* [x] **Procedural query language**
* [ ] None of the above

**Solution description:** Relational Algebra is a procedural query language in which the user specifies the set of operations to be performed sequentially to get the desired output.

**Options:**
