## 1. SQL COMMIT Statement

**Problem Statement:** What does the COMMIT statement do?

* **Options:**
* Reverts changes
* **Saves changes** (Correct)
* Groups data
* Joins tables


* **Solution Description:** COMMIT saves all changes made during the transaction.

## 2. ER Basics 3

**Problem Statement:** In DBMS, the E-R modeling technique is a:

* **Options:**
* **Top-down approach** (Correct)
* Bottom-up approach
* Left-right approach
* None of the above


* **Solution Description:** The E-R modeling technique is a top-down approach.

## 3. Storage Structure

**Problem Statement:** Which of the following model tells how data will be on the disk?

* **Options:**
* **Physical data model** (Correct)
* Creational data model
* Conceptual data model
* Representational data model


* **Solution Description:** Physical Data model represents the physical structure of the database which includes planning of how the data will be organised, stored on the disk and various access methods available for it.

---

## 4. Referential Integrity

**Problem Statement:** Referential integrity constraint in DBMS states that foreign key should have a matching primary key or it must be not Null.

* **Options:**
* True
* **False** (Correct)


* **Solution Description:** False. Referential integrity in a DBMS ensures a foreign key either matches a primary key in the referenced table or is NULL (if permitted). The statement wrongly states the foreign key "must be not NULL".

---

## 5. Views

**Problem Statement:** SQL views are also known as

* **Options:**
* Simple tables
* **Virtual tables** (Correct)
* Complex tables
* Actual Tables


* **Solution Description:** A view is also known as a virtual table because it contains rows and columns similar to a real table. It presents the table interface but cannot be stored as a physical table in the database.
