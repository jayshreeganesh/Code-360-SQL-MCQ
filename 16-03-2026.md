## 4. 1NF Requirements

**Problem Statement:** In DBMS, which of the following is not required for a table to be in 1NF?

* **Options:**
* Attributes to have unique names
* **Free from Transitive dependencies** (Correct)
* Single valued attribute
* Each value in an attribute is of a similar type.



**Solution description:** For a relation to justifying 1NF, it needs to satisfy 4 basic conditions: 1. Each attribute should contain atomic values. 2. Each Value stored in an attribute should be of the same type. 3. All the attributes in a table should have unique names. 4. The order of the data stored in the table doesn't matter.
