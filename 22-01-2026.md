## 2. Indirect Functional Dependency (FD)

* **Problem Statement:** A __________ is an indirect functional dependency, one in which  only by virtue of  and  in database.
* **Options:**
* Multivalued Dependencies
* Join Dependency
* Trivial Functional Dependency
* **Transitive Dependency** (Correct)


* **Solution Description:** Third Normal Form (3NF) deals with 'transitive' dependencies. This means if we have a primary key A and non-key domains B and C, where C is more dependent on B than A, and B is directly dependent on A, then C can be considered transitively dependent on A.

## 3. Safe Concurrency

* **Problem Statement:** Which of the following concurrency control protocols ensure both conflict serializability and free from deadlock?
* **Options:**
* **a. Timestamp ordering** (Correct)
* b. 2 Phase locking
* c. Both (a) and (b)
* d. None


* **Solution Description:** 2-Phase locking ensures conflict serializability but may lead to deadlock. Timestamp-based concurrency control ensures conflict serializability and is non-locking, meaning it cannot enter a deadlock state.

## 4. Commit Rollback

* **Problem Statement:** You can roll back after performing the commit in MySQL.
* **Options:**
* True
* **False** (Correct)
* Depends on the Transaction


* **Solution Description:** DBMS transactions have many queries, but there are no queries that will 'undo' the committed changes. Unless the user has a backup, they cannot Rollback after performing a Commit.

## 5. Non-Clustered Index

* **Problem Statement:** How non-clustered index point to the data?
* **Options:**
* **Points to rows with key values** (Correct)
* It never points to anything
* It points to a data row
* None of the mentioned


* **Solution Description:** It is used for pointing to data rows containing key values. Non-clustered indexes have a structure separate from the data rows. A non-clustered index contains the index key values, and each entry has a pointer to the data row containing that value.
