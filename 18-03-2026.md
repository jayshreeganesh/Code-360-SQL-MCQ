## 3. Data Export
**Problem Statement:** Choose the correct query for Exporting data in SQL, from the following.

* [ ] `SELECT * FROM UFC WHERE id = 1 INTO OUTFILE 'C:/tmp/conner_vs_khabib2.csv';`
* [**x**] **`SELECT * FROM UFC WHERE id = 1 INTO OUTFILE 'C:/tmp/conner_vs_khabib2.csv' FIELDS ENCLOSED BY '"' TERMINATED BY ',' ESCAPED BY '"' LINES TERMINATED BY '\r\n';`**
* [ ] `SELECT * FROM UFC WHERE id = 1 INTO OUTFILE 'C:/tmp/conner_vs_khabib2.csv' FIELDS TERMINATED BY ',' ENCLOSED BY '"' LINES TERMINATED BY '\n' IGNORE 1 ROWS;`
* [ ] `SELECT * FROM UFC WHERE id = 1 LOAD DATA OUTFILE 'C:/tmp/conner_vs_khabib2.csv' FIELDS TERMINATED BY ',' ENCLOSED BY '"' LINES TERMINATED BY '\n' IGNORE 1 ROWS;`

**Solution Description:**
To export our data into a CSV file. Query: `SELECT column_name(s) FROM T_name WHERE id = 1 INTO OUTFILE 'C:/tmp/xyz_exported.csv' FIELDS ENCLOSED BY '"' TERMINATED BY ',' ESCAPED BY '"' LINES TERMINATED BY '\r\n'`. 
1. **FIELDS ENCLOSED BY** is used when we have to export the data from the specific field.
2. **TERMINATED BY** is used when we have to terminate the data after export.
3. **LINES TERMINATED BY** is to terminate the specific line after exporting the data.

## 4. Clustering Drawbacks
**Problem Statement:** Which of the following is not an advantage of database clustering?

* [ ] Load Balancing
* [ ] Data Redundancy
* [ ] Increased Availability
* [**x**] **Decreased Availability**

**Solution Description:**
Clustering is the process of combining more than one server or instance holding the same database. Clustering helps us with features like:
1. **Data Redundancy:** Storing the same data at multiple servers.
2. **Load Balancing:** Helps servers handle a large number of requests.
3. **Increased Availability:** If one database/server fails, others can be used to access the data.
