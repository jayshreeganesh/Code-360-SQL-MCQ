**Problem Statement:** What is the purpose of LIKE in SQL?

## 2. Relational Model

**Problem Statement:** In a relational model in DBMS, which of the following indicates the cardinality:

* [ ] Number of attributes
* [ ] Number of keys
* [x] **Number of tuples**
* [ ] Number of relations

**Solution Description:** In relational model, cardinality refers to the number of tuples present in a relation or table.

## 5. Constraint Violation

**Problem Statement:** In following table in Database, which integrity constraint is being violated?

| Book_name | Book_code | Book_price | Author_name | Publish_date |
| --- | --- | --- | --- | --- |
| Physics-1 | 011 | 180 | Dr. Raj Nag | 21-03-1996 |
| Chemistry-1 | 021 | 200 | Dr. Kiran Sethi | 25-2-2001 |
| Maths-1 | 031 | 175 | Vipul Sen | 1-6-2006 |
| Grammar-1 | 021 | 150 | Dr. Jay | 11-6-2020 |

**Note:** `Book_code` is the primary key.

* [ ] Referential Integrity constraint
* [x] **Entity Integrity constraint**
* [ ] Domain constraint
* [ ] None of the above

**Solution Description:** The `Book_code` column has `021` value twice for two different books. So, it violates the Entity Integrity Constraint since every table should have a primary key to identify each row uniquely and in this table the primary key is not unique.
