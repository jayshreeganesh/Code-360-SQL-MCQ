## 2. Clustering Drawbacks

**Problem Statement:** Which of the following is not an advantage of database clustering?

* **Options:**
* Load Balancing
* Data Redundancy
* Increased Availability
* **Decreased Availability** (Correct)



**Solution Description:**
Clustering is the process of combining more than one server or instance holding the same database. Clustering helps with:

1. **Data Redundancy:** Helps by storing the same data at multiple servers.
2. **Load Balancing:** Helps reduce load by distributing requests across multiple servers.
3. **Increased Availability:** If one server fails, others remain available to handle requests.

## 3. Transaction Control

**Problem Statement:** Suppose we have created a savepoint named Spt1, which of the following commands in SQL can be used to rollback the transactions executed after creating the savepoint?

* **Options:**
* RELEASE SAVEPOINT Spt1
* COMMIT Spt1
* **ROLLBACK TO Spt1** (Correct)
* ROLLBACK



**Solution Description:**

* **ROLLBACK:** This undoes all changes or restores the current state to any previously saved state.
* **ROLLBACK TO savepoint:** This undoes the current state and restores it specifically to the designated savepoint.

## 4. RDBMS Basics

**Problem Statement:** RDBMS consists of a collection of?

* **Options:**
* **Tables** (Correct)
* Fields
* Records
* Keys



**Solution Description:**
In an RDBMS, data is organized into tables, where each table represents a relation composed of rows (records) and columns (attributes). This structured format allows for efficient data storage, retrieval, and manipulation.
