## 1. SQL INNER JOIN

**Problem Statement:** What does an **INNER JOIN** return in SQL?

**Options:**

* All records from both tables
* **Only matching records** (Correct)
* Only unmatched records
* First table records

**Solution Description:** `INNER JOIN` returns rows when there is a match in both tables.

## 2. order by

**Problem Statement:** If you don't specify `ASC` or `DESC` after a SQL `ORDER BY` clause, the following is used by default: ________.

**Options:**

* **ASC** (Correct)
* DESC
* There is no default value
* None of the mentioned

**Solution Description:** `ASC` is the default sort order. Null values are treated as the lowest possible values.

## 3. Table Properties

**Problem Statement:** Which of the following is **not** a property of the table in DBMS?

**Options:**

* Every column should have a unique name
* **An attribute can have multiple values for a row** (Correct)
* Column values should be of same type
* Sequence of rows is insignificant

**Solution Description:** A relation should contain atomic values, so multiple values for an attribute should be avoided.

## 4. Set operators

**Problem Statement:** In precedence of set operators, the expression is evaluated from:

**Options:**

* Left to left
* **Left to right** (Correct)
* Right to left
* From user specification

**Solution Description:** The expression is evaluated from left to right according to the precedence.
