### **1. SQL LIKE Operator**
* **Problem Statement:** What is the purpose of `LIKE` in SQL?
* **Selected Answer:** **Pattern matching** (Correct)
* **Solution Description:** `LIKE` is used for pattern matching with wildcards (such as `%` and `_`).

### **2. Deadlock Prone**
* **Problem Statement:** Which of the following Concurrency controls is prone to deadlocks?
* **Selected Answer:** **Lock Based Control** (Correct)
* **Solution Description:** Deadlock is a situation where transactions try to access locks on already locked data items. In contrast, in timestamp-based control, each transaction is allocated a time slot, so it cannot enter a deadlock.

### **3. Relational Model**
* **Problem Statement:** In a relational model in DBMS, which of the following indicates the cardinality?
* **Selected Answer:** **Number of tuples** (Correct)
* **Solution Description:** In a relational model, cardinality refers to the number of tuples (rows) present in a relation or table. (Note: The number of columns is known as the **degree**).

### **4. SQL Database**
* **Problem Statement:** SQL uses \_\_\_\_\_\_ format to store data.
* **Selected Answer:** **tables** (Correct)
* **Solution Description:** SQL is a structured, relational database that uses tables to store data. It has rows and columns and uses a tabular format.

### **5. Commands DDL**
* **Problem Statement:** SQL has how many main commands for DDL?
* **Selected Answer:** **3** (Correct)
* **Solution Description:** `CREATE`, `DROP`, and `ALTER` are considered the 3 main DDL (Data Definition Language) commands.
    > *Note: While some systems include `TRUNCATE` or `RENAME`, these three are the fundamental core.*
