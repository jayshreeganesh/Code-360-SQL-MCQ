## **Quiz Summary: Database Management Systems (DBMS)**

### **1. SQL COMMIT Statement**

* **Problem Statement:** What does the `COMMIT` statement do?
* **Correct Option:** Saves changes
* **Solution Description:** `COMMIT` saves all changes made during the transaction.

### **2. CRUD Operations**

* **Problem Statement:** What does **R** refer to in CRUD operations in DBMS?
* **Correct Option:** Read
* **Solution Description:** For the persistent storage in DBMS, four basic operations that are known as CRUD operations are as follows:
1. **C** in CRUD stands for **Create**. It is accomplished using the `INSERT` statement in SQL.
2. **R** in CRUD stands for **Read**. It is accomplished using the `SELECT` statement in SQL.
3. **U** in CRUD stands for **Update**. It is accomplished using `UPDATE` statements in SQL.
4. **D** in CRUD stands for **Delete**. It is accomplished using the `DELETE` statement in SQL.



### **3. Incremental vs Full Backup**

* **Problem Statement:** How does an incremental backup differ from a full backup?
* **Correct Option:** It captures only the changes made since the last backup.
* **Solution Description:** Incremental backups save only the data that has changed since the last full or incremental backup, reducing storage requirements and speeding up the backup process.

### **4. Relational Algebra**

* **Problem Statement:** In the context of DBMS, relational algebra is:
* **Correct Option:** Procedural query language
* **Solution Description:** Relational Algebra is a procedural query language in which the user specifies the set of operations to be performed sequentially to get the desired output.

### **5. Deadlock in Databases**

* **Problem Statement:** What is a deadlock in the context of database transactions?
* **Correct Option:** A state where multiple transactions are waiting for each other to release resources, causing a circular wait.
* **Solution Description:** A deadlock occurs when two or more transactions hold resources and simultaneously request resources held by each other, creating a circular wait that prevents any transaction from proceeding.
