## 1. Update Ages MCQ

**Problem statement**

> A university has a dataset with columns: `Id`, `Name`, `Age`.
> The dataset was last updated 1 year ago, so every person is now 1 year older.
> Choose the most appropriate SQL option to update the dataset with correct ages.

**Options**

- `UPDATE * in University Age=Age+1;`
- `UPDATE University SET Age = Age + 1;` ✅
- `UPDATE University SET ALL Age=Age+1;`
- `We cannot update all the rows at once.`

**Explanation**

> Use a single `UPDATE` statement without a `WHERE` clause to increment the `Age` column for all rows.
