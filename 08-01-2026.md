## 1. SQL ROLLBACK Statement

**Problem Statement:** What does ROLLBACK do in DBMS?

* **Options:**
* Saves changes
* **Reverts changes** (Correct)
* Joins tables
* Groups data


* **Solution Description:** ROLLBACK undoes all changes made during the transaction.

## 2. Relational Algebra: Unary Operations

**Problem Statement:** In the context of DBMS, which of the following is not a valid unary operation in relational algebra?

* **Options:**
* Select
* **Min** (Correct)
* Project
* Rename


* **Solution Description:** Unary operations act on a single relation. Select (), Project (), and Rename () are unary, whereas Min is an aggregate function.

## 5. Relational Model Cardinality

**Problem Statement:** In a relational model in DBMS, which of the following indicates the cardinality:

* **Options:**
* Number of attributes
* Number of keys
* **Number of tuples** (Correct)
* Number of relations


* **Solution Description:** In the relational model, cardinality refers to the number of tuples (rows) present in a relation or table.
