## Question 3: Differential Backup Advantage

**Problem Statement:**
What is a key advantage of a differential backup over an incremental backup?

**Options:**

* [ ] It requires less storage space than incremental backups.
* [x] **It simplifies recovery by requiring only the full backup and the latest differential backup.**
* [ ] It captures changes made since the last incremental backup.
* [ ] It acts as a standalone backup that doesn't rely on other backups.

**Solution Description:**
Differential backups copy all changes made since the last full backup. For recovery, only the full backup and the most recent differential backup are needed, streamlining the restoration process.

## Question 5: 1NF Requirements

**Problem Statement:**
In DBMS, which of the following is not required for a table to be in 1NF?

**Options:**

* [ ] Attributes to have unique names
* [x] **Free from Transitive dependencies**
* [ ] Single valued attribute
* [ ] Each value in an attribute is of a similar type.

**Solution Description:**
For a relation to justifying 1NF, it needs to satisfy 4 basic conditions:

1. Each attribute should contain atomic values.
2. Each Value stored in an attribute should be of the same type.
3. All the attributes in a table should have unique names.
4. The order of the data stored in the table doesn't matter.
