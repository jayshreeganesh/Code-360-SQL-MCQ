## 1. SQL Foreign Key
* **Problem Statement:** What is the purpose of a Foreign Key in DBMS?
* **Options:**
    * Uniqueness
    * **Data integrity (Correct)**
    * Data indexing
    * Sort data
* **Solution Description:** Foreign Key enforces referential integrity between tables.

---

## 2. Indexing Structure Basics
* **Problem Statement:** In a multi-level index, what does the first-level index typically point to?
* **Options:**
    * The entries in the second-level index.
    * **The raw data blocks in the database. (Correct)**
    * The entries in the third-level index.
    * The memory used by the database engine.
* **Solution Description:** The first-level index contains references (pointers) to the blocks of raw data in the database table. These entries enable faster access to the actual data.

## 3. Transaction mode
* **Problem Statement:** In DBMS, if a transaction has obtained a __________ lock, it can read but cannot write on the item.
* **Options:**
    * **Shared mode (Correct)**
    * Exclusive mode
    * Read only mode
    * Write only mode
* **Solution Description:** If a transaction $T_i$ has obtained a shared-mode lock (denoted by $S$) on item $Q$, then $T_i$ can read, but cannot write, $Q$.

---

## 4. Parameter Types
* **Problem Statement:** Which procedure parameter enables the caller to pass in a value and get back a value in DBMS?
* **Options:**
    * **INOUT (Correct)**
    * IN
    * OUT
    * GOINOUT
* **Solution Description:** The procedure parameter that enables the caller to pass in a value and get back a value in DBMS is the IN OUT parameter.

## 5. Functional query
* **Problem Statement:** What is the meaning of LIKE '%0%0%' in SQL?
* **Options:**
    * Feature begins with two 0's
    * Feature ends with two 0's
    * Feature has more than two 0's
    * **Feature has two 0's anywhere (Correct)**
* **Solution Description:** The LIKE operator is used in a WHERE clause to search for a specified pattern in a column.
