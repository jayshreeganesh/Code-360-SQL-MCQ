## Screenshot 2 – Schema Mapping MCQ

**Problem statement**

> Which of the following relational database schemas is a correct representation for the following ER diagram:

ER diagram description (from image):

- Entity: `Student` (rectangle)
- Attributes: `Name`, `Phone No.`, `Course`, `Roll No.` (single-valued); `Address` (multi-valued)
- `Address` further has attributes: `House No.`, `City`

**Options**

1. `Student(Name, Phone no., Course, Roll No., House no., City)`
2. `Student(Name, Phone no., Course, Roll No.) Address(House no., City, Roll no.) ✅`
3. `Student(Name, Phone no., Course, Roll No., Address, House no., City, Roll no.)`
4. All of the above

**Solution description (summary)**

- Rectangle in ER diagram → entity sets.
- Ellipse → attributes; double ellipse → multi-valued attributes.
- Rules:
    - Each strong entity set converts to a relation with the same name.
    - Attributes of entity set become attributes in the relation.
    - For each multi-valued attribute, create a separate relation including the primary key of the parent entity as a foreign key.
- Here, `Student` has attributes `Name`, `Roll No.`, `Phone No.`, `Course`, `Address`; `Address` is multi-valued.
- So relation `Student` has attributes `(Name, Phone No., Course, Roll No.)`.
- New relation `Address(House No., City, Roll No.)` is created, with `Roll No.` as foreign key referencing `Student`.

## Screenshot 4 – Relational Matching MCQ

**Problem statement**

> Match the components of relational model which are same:

Left side:

- a. Tuples
- b. Column
- c. Table

Right side:

1. Relation
2. Field
3. Rows/Record

**Correct matching**

- a → 3 (Tuples ↔ Rows/Record)
- b → 2 (Column ↔ Field)
- c → 1 (Table ↔ Relation)

Correct option: **a3 b2 c1 ✅**

**Solution description**

- A tuple in the relational model is represented by a row, also known as a record.
- Columns are denoted by fields of the table, also called attributes.
- The table is similar to relation in the relational model.
