- A) Compare exact values
- **B) Pattern matching**
- C) Sort data
- D) Group data

## 2. DBMS Efficiency Challenges
**Problem Statement:** Which of the following is a potential performance issue of DBMS?

**Options:**
- A) It eliminates the need for data security measures
- **B) It introduces performance overhead due to abstraction layers**
- C) It reduces the need for data normalization
- D) It enhances the speed of manual queries

**Solution Description:** 
DBMS often introduces performance overhead due to additional layers of abstraction, which may cause latency when processing queries or transactions.

## 3. DBMS Architecture
**Problem Statement:** In the context of DBMS, if your laptop has an application like MS Access that is fetching data from another system, it is an example of which type of architecture?

**Options:**
- A) 1 tier
- **B) 2 tier**
- C) 3 tier
- D) None of the above.

**Solution Description:** 
In a two-tier architecture, an interface runs on a client and a data layer is stored on a server. Since MS Access on a laptop is fetching data from a database on another system, it fits this model.

## 4. Handling Large Indexes
**Problem Statement:** What happens when the first-level index in a database becomes too large?

**Options:**
- A) The system stops using indexes for searches.
- **B) A second-level index is created to point to entries in the first-level index.**
- C) The first-level index is divided into smaller tables.
- D) The database automatically optimizes queries without using the index.

**Solution Description:** 
When the first-level index is too large for memory, a second-level index is created to point to its entries, enabling efficient management of large datasets.
