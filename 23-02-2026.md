## **Quiz Summary: Database Management Systems (DBMS)**

### **1. SQL ORDER BY Clause**

* **Question:** What is the purpose of ORDER BY?
* **Options:**
* Join tables
* Filter data
* Group data
* **Sort data** (Correct)


* **Solution Description:** `ORDER BY` sorts the result set in ascending or descending order.

---

### **2. Database Definition**

* **Question:** Anything which stores only unstructured data can be called a Database.
* **Options:**
* True
* **False** (Correct)


* **Solution Description:** It is not true as a database can contain both structured and unstructured data. Relational Databases contain only structured data whereas NoSQL (e.g., MongoDB) can contain unstructured data.

---

### **3. Normal Form**

* **Question:** Every constraint on the table is a logical consequence of the table's in DBMS.
* **Options:**
* Fourth normal form
* Fifth normal form
* **Domain/key normal form** (Correct)
* None of the Mentioned


* **Solution Description:** A relation is in domain-key normal form (DK/NF) if every constraint on the relation is a logical consequence of the definition of keys and domains.

---

### **4. ACID Property**

* **Question:** The "all-or-none" property is commonly referred to as __________.
* **Options:**
* Isolation
* Durability
* **Atomicity** (Correct)
* None of the mentioned


* **Solution Description:** The all or none policy is commonly referred to as atomicity. It ensures that work is either completed or not completed and there are no intermediate stages.

---

### **5. Transactions**

* **Question:** Collections of operations that form a single logical unit of work are called __________.
* **Options:**
* Views
* Networks
* Units
* **Transactions** (Correct)


* **Solution Description:** Collections of operations that form a single logical unit of work are called transactions. A database system must ensure the proper execution of the transaction.
