## 2. Projection

**Problem Statement:** Which clause from the following corresponds to the projection operation of the relational algebra?

* **Options:**
* From
* **Select** (Correct)
* Where
* None of these


* **Note:** In SQL, the `SELECT` clause handles projection (choosing specific columns), while the `WHERE` clause handles selection (choosing specific rows).

## 3. Functional Query

**Problem Statement:** What is the meaning of `LIKE '%0%0%'` in SQL?

* **Options:**
* Feature begins with two 0's
* Feature ends with two 0's
* Feature has more than two 0's
* **Feature has two 0's anywhere** (Correct)


* **Solution Description:** The `LIKE` operator is used in a `WHERE` clause to search for a specified pattern in a column. The `%` wildcard represents zero or more characters.

## 5. 1NF Requirements

**Problem Statement:** In DBMS, which of the following is not required for a table to be in 1NF (First Normal Form)?

* **Options:**
* Attributes to have unique names
* **Free from Transitive dependencies** (Correct)
* Single valued attribute
* Each value in an attribute is of a similar type.


* **Solution Description:** For a relation to justify 1NF, it needs to satisfy 4 basic conditions:
1. Each attribute should contain atomic values.
2. Each value stored in an attribute should be of the same type.
3. All the attributes in a table should have unique names.
4. The order of the data stored in the table doesn't matter.


* **Note:** Being "Free from Transitive dependencies" is a requirement for **3NF (Third Normal Form)**, not 1NF.
