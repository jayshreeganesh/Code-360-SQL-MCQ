## **2. Clustered Index**

* **Problem Statement:** Which one is true about the clustered index?
* **Selected Answer:** **Built on unique key by default** (Correct)
* **Solution Description:** A clustered index is built by default on unique key columns. Non-clustered indexes have a structure separate from the data rows. A non-clustered index contains the non-clustered index key values, and each key-value entry has a pointer to the data row that contains the key value.

## **3. Transaction Control**

* **Problem Statement:** Suppose we have created a savepoint named `Spt1`, which of the following commands in SQL can be used to rollback the transactions executed after creating the savepoint?
* **Selected Answer:** **ROLLBACK TO Spt1** (Correct)
* **Solution Description:** `ROLLBACK` transaction - This TCL command undoes all the changes or restores the current state to any previously saved state.
* **General form:** `ROLLBACK`: This rolls back the previously committed command to its initial state.
* `ROLLBACK TO savepoint`: This undoes the current state and restores it to the savepoint.
