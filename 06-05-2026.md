## 3. DBMS Facts
**Problem Statement:**
Which of the following is true in DBMS?

**Options:**
*   **We can have multiple candidate keys** (Correct)
*   We can have multiple primary keys
*   The value of primary key can be same for 2 tuples
*   Alternate key and primary key are the same.

**Solution Description:**

## 5. Query Filter
**Problem Statement:**
In the context of a DBMS, which of the following should be used to list down all the names of the Book whose Book_price is less than 100 from the relation 'Book':

**Options:**
*   $\sigma_{Book\_name, Book\_price < 100}(Book)$
*   **$\Pi_{Book\_name}(\sigma_{Book\_price < 100}(Book))$** (Correct)
*   $\sigma_{Book\_name}(\sigma_{Book\_price < 100}(Book))$
*   $\Pi_{Book\_price < 100}(Book)$

**Solution Description:**
To list down all the names of the Book whose Book_price is less than 100 from the relation 'Book', we can use the projection operator ($\Pi$) on the `book_name` attribute which is used to display the output. Then use the Selection operator ($\sigma$) on the `book_price` attribute to fulfill the condition present in the question. The selection operator will get the desired data.
