## 1. SQL GROUP BY Clause

**Problem Statement:** What is the purpose of `GROUP BY`?

**Options:**

* [ ] Filter rows
* [x] **Group rows**
* [ ] Sort rows
* [ ] Join tables

## 2. Schema Mapping

**Problem Statement:** Which of the following relational database schemas is a correct representation for the following ER diagram?

*(Note: The diagram shows a "Student" entity with attributes: Name, Phone No., Course, Roll No., and a multi-valued "Address" attribute containing House no. and City.)*

**Options:**

* [ ] Student(Name, Phone no., Course, Roll No., House no., City)
* [x] **Student(Name, Phone no., Course, Roll No.) Address(House no., City, Roll no.)**
* [ ] Student(Name, Phone no., Course, Roll No., Address, House no., City, Roll no.)
* [ ] All of the above

**Solution Description:** In the ER diagram, double ellipses represent multi-valued attributes. For each multi-valued attribute, we create a separate table and include the primary key of the strong entity set as a foreign key. Thus, "Address" becomes its own relation linked by "Roll No."

## 4. order by

**Problem Statement:** If you don't specify `ASC` or `DESC` after a SQL `ORDER BY` clause, the following is used by default __________.

**Options:**

* [x] **ASC**
* [ ] DESC
* [ ] There is no default value
* [ ] None of the mentioned

**Solution Description:** `ASC` (Ascending) is the default sort order. Null values are treated as the lowest possible values.

## 5. Data Abstraction

**Problem Statement:** Which of the following data models describes the database at the highest level in DBMS?

**Options:**

* [x] **Conceptual data model**
* [ ] Physical data model
* [ ] Network data model
* [ ] Hierarchical data model

**Solution Description:** A Conceptual Data Model describes and conveys high-level relationships between concepts/entities. It helps an organization see their data and the relationships between distinct data.
