### **2. Index Components**

* **Problem Statement:** In DBMS, the index consists of:
* **Options:**
* [ ] list of keys
* [ ] pointers to the key in the table
* [x] **both (a) and (b)**
* [ ] none


* **Solution Description:** The index is a data structure used to perform indexing. It contains:
1. A search key (copy of the primary key) to reduce access time.
2. Data references (pointers) holding the address of the disk block where the value is stored.
