## DBMS Facts

**Question:**
Which of the following is true in DBMS?

- We can have multiple candidate keys ✅
- We can have multiple primary keys
- The value of primary key can be same for 2 tuples
- Alternate key and primary key are the same

**Explanation:**
A relation can have multiple candidate keys, one of which is chosen as the primary key, and the remaining candidate keys are called alternate keys.
