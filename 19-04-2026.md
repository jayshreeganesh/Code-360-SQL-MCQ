## 1. SQL BETWEEN Operator
**Problem Statement:** What does the `BETWEEN` operator do in SQL?

* **Options:**
    * Joins tables
    * Compares two values
    * **Checks within a range** (Correct)

## 3. Clustering Drawbacks
**Problem Statement:** Which of the following is **not** an advantage of database clustering?

* **Options:**
    * Load Balancing
    * Data Redundancy
    * Increased Availability
    * **Decreased Availability** (Correct)

**Solution Description:** Clustering is the process of combining more than one server or instance holding the same database. Clustering helps with:
1.  **Data Redundancy:** Stores the same data at multiple servers.
2.  **Load Balancing:** Helps servers handle a large volume of requests.
3.  **Increased Availability:** If one server fails, others remain available.

## 4. Semester Update (SQL Syntax)
**Problem Statement:** Which of the following is the most efficient way in SQL to update the current value of "Semester" attribute by 1, for all the rows of the table 'Student':

* **Options:**
    * Write 'n' update commands, if 'n' number of rows are present in the table.
    * Instead of updating, insert all the records again in the table.
    * **Update Student SET Semester= Semester + 1;** (Correct)
    * We cannot update all the rows at once.

**Solution Description:** We can update all rows at once. This is possible because we have not used any `WHERE` condition to limit the rows.

## 5. DBMS Functionality
**Problem Statement:** Which of the following best describes the primary function of a Database Management System (DBMS)?

* **Options:**
    * To only store data
    * **To ensure efficient data retrieval and management** (Correct)
    * To convert data into flat files
    * To enhance file system performance

**Solution Description:** A DBMS acts as an interface between end-users and databases, helping in organizing, retrieving, and managing data effectively, which goes beyond just storing data.
