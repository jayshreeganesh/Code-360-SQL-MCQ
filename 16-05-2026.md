## **DBMS & SQL Quiz Recap**

### **1. SQL WHERE Clause**

**Problem Statement:** What is the purpose of the **WHERE** clause in SQL?

* [ ] Order data
* [x] **Filter data**
* [ ] Join tables
* [ ] Group data

> **Solution Description:** `WHERE` is used to filter records in a query.

### **2. Non-Clustered Index**

**Problem Statement:** How does a **non-clustered index** point to the data?

* [x] **Points to rows with key values**
* [ ] It never points to anything
* [ ] It points to a data row
* [ ] None of the mentioned

> **Solution Description:** It is used for pointing to data rows containing key values. Non-clustered indexes have a structure separate from the data rows. A non-clustered index contains the non-clustered index key values, and each key-value entry has a pointer to the data row that contains the key value.

### **3. CRUD Operations**

**Problem Statement:** What does **R** refer to in CRUD operations in DBMS?

* [ ] Replicate
* [x] **Read**
* [ ] Redundant
* [ ] Replace

> **Solution Description:** For persistent storage in DBMS, four basic operations known as CRUD are:
> 1. **C**: Create (`INSERT` statement)
> 2. **R**: Read (`SELECT` statement)
> 3. **U**: Update (`UPDATE` statement)
> 4. **D**: Delete (`DELETE` statement)

### **4. Null Values**

**Problem Statement:** In DBMS, which of the following aggregate functions does **not** ignore null values?

* [ ] Max(attribute)
* [ ] Count(attribute)
* [ ] Min(attribute)
* [x] **Count(*)**
* [ ] Both ii) and iv)
* [ ] Both i) and iii)

> **Solution Description:** `*` selects all values including null; thus, `count(*)` considers null values also.

### **5. Read Lock**

**Problem Statement:** Which of the following is the query to apply a **Read Lock** on table **Employees** in DBMS?

* [x] **LOCK TABLE Employees READ;**
* [ ] LOCK TABLE Employees READ|WRITE;
* [ ] LOCK TABLE Employees PRIORITY READ;
* [ ] LOCK TABLE Employees READ ONLY;

> **Solution Description:** READ LOCK allows a user to only read the data from a table. The syntax for READ LOCK is `LOCK TABLES T_name READ`.
