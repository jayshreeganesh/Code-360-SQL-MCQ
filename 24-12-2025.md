## Question 4 – Transaction mode (Locks)

**Problem statement**

> In DBMS, if a transaction has obtained a ______ lock, it can read but cannot write on the item.

**Options**

- **Shared mode** ✅
- Exclusive mode
- Read only mode
- Write only mode

**Explanation**

> If a transaction $T_i$ has obtained a shared-mode lock (denoted by `S`) on item `Q`, then $T_i$ can read, but cannot write, `Q`.

***

## Question 5 – Deadlock prone control

**Problem statement**

> Which of the following concurrency controls is prone to deadlocks?

**Options**

- Timestamp based control
- **Lock based control** ✅
- Both (a) and (b)
- None

**Explanation**

> Deadlock is a situation where transactions try to access locks on already locked data items. In timestamp-based control, each transaction is allocated a time slot, so it cannot enter a deadlock.
