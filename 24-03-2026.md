## 2. Index Drawbacks
**Problem Statement:** Which of the following operations does indexing slow down in SQL?
1. DELETE
2. INSERT
3. SELECT
4. READ

* **Options:**
    * ( ) Only 1,3
    * ( ) Only 2,4
    * ( ) Only 1,2 **[Correct]**
    * ( ) Only 1,2,4
* **Solution Description:** Indexing results in the reduction of the speed of execution of write operations in the memory. Major Write operations are INSERT, UPDATE and DELETE operations.

## 5. Database Partitioning
**Problem Statement:** Partitioning of the database is usually committed when:

* **Options:**
    * ( ) a. Dealing with huge dataset, which one server alone cannot handle.
    * ( ) b. The requests to database access are taking longer time to be accepted i.e. long response time.
    * ( ) c. Both (a) and (b) **[Correct]**
    * ( ) d. None of the Above
* **Solution Description:** Partitioning is a technique that is used to divide stored database objects into separate servers. Due to this, there is an increase in performance as well as the increase in controllability of the data. We can manage huge chunks of data optimally. Partitioning is committed when we are dealing with a huge dataset or the request are taking more time than expected.
