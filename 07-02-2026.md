## 2. Primary Constraint

**Problem Statement:** Entity integrity states that primary key should be:

* **Options:**
* Null
* **Not null** (Correct)
* Null and Not null
* zero


* **Solution Description:** Entity Integrity Constraint puts constraints on Primary key i.e. primary should be unique and does not have NULL value.

## 3. Dirty Read Example

**Problem Statement:** Which of the following is an example of a dirty read in database transactions?

* **Options:**
* **A transaction reads data that another transaction has not yet committed.** (Correct)
* A transaction updates the same record as another transaction, overwriting changes.
* A transaction retrieves inconsistent results due to other transactions inserting or deleting rows.
* A transaction locks a table, preventing others from accessing it.


* **Solution Description:** A dirty read occurs when one transaction reads uncommitted changes made by another transaction. If the changes are later rolled back, the data read becomes invalid.

## 4. Transaction Phase

**Problem Statement:** In DBMS, a transaction that has not been completed successfully is called ________.

* **Options:**
* Compensating transaction
* **Aborted transaction** (Correct)
* Active transaction
* Partially committed transaction


* **Solution Description:** An aborted transaction is a state after the transaction has been rolled back and the database has been restored to the state prior to the transaction.

## 5. Query Processor Role

**Problem Statement:** What is the role of the Query Processor in a DBMS?

* **Options:**
* To manage data consistency during transactions
* To execute low-level database operations
* **To optimize and execute SQL queries** (Correct)
* To store and retrieve data from the database


* **Solution Description:** The Query Processor interprets, optimizes, and executes SQL queries, converting high-level commands into low-level operations that can be performed by the DBMS.
