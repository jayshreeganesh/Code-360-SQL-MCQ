* **Question:** In SQL, `ALTER` command is a type of:
* **Options:**
* Data Manipulation Language
* **Data Definition Language** (Correct)

* **Solution Description:** `ALTER` commands modify the structure of the table and hence is a kind of Data Definition Language.

* **Question:** Which of the following is a key advantage of DBMS over file systems regarding data consistency?
