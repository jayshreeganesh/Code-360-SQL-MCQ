## 2. 3-Tier Architecture

**Problem Statement:** In 3-tier architecture, which of the following deals with the physical storage of data in DBMS?

**Options:**

* External schema
* **Internal schema** (Correct)
* Conceptual schema
* All of the above

**Solution Description:**
The internal schema describes the physical storage structure of the database. It is a very low-level representation of the complete database.

## 4. Clustered Index

**Problem Statement:** Which one is true about the clustered index?

**Options:**

* Not linked with table
* **Built on unique key by default** (Correct)
* Not built on unique key
* None of the mentioned

**Solution Description:**
A clustered index is built by default on unique key columns. Non-clustered indexes have a structure separate from the data rows. A non-clustered index contains the non-clustered index key values and each key-value entry has a pointer to the data row that contains the key value.

## 5. Read Lock

**Problem Statement:** Which of the following is the query to apply Read Lock on table **Employees** in DBMS?

**Options:**

* **LOCK TABLE Employees READ;** (Correct)
* LOCK TABLE Employees READ|WRITE;
* LOCK TABLE Employees PRIORITY READ;
* LOCK TABLE Employees READ ONLY;

**Solution Description:**
READ LOCK allows a user to only read the data from a table. The syntax for READ LOCK is `LOCK TABLES T_name READ`.
