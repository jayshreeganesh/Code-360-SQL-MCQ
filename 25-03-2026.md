## 1. SQL ROLLBACK Statement
**Problem Statement:** What does ROLLBACK do in DBMS?

**Options:**
* Saves changes
* **Reverts changes** (Correct)
* Joins tables
* Groups data

**Solution Description:** ROLLBACK undoes all changes made during the transaction.

## 3. 1NF Requirements
**Problem Statement:** In DBMS, which of the following is not required for a table to be in 1NF?

**Options:**
* Attributes to have unique names
* **Free from Transitive dependencies** (Correct)
* Single valued attribute
* Each value in an attribute is of a similar type.

**Solution Description:** For a relation to justifying 1NF, it needs to satisfy 4 basic conditions: 
1. Each attribute should contain atomic values. 
2. Each Value stored in an attribute should be of the same type. 
3. All the attributes in a table should have unique names. 
4. The order of the data stored in the table doesn't matter.

*(Note: Transitive dependency removal is a requirement for 3NF, not 1NF.)*

## 4. Entity Relationships
**Problem Statement:** In DBMS, an entity can be:

**Options:**
* Related to one entity only
* Related only to itself
* Related to two entities
* **Related to many entities** (Correct)

**Solution Description:** An entity can be related to many different entities, including itself. For an University ER diagram, the entity Course can be related to entities such as: Students, Professor, Fees, Workshops etc.
