## **DBMS Quiz: Questions and Answers**

### **1. One to Many Relationship**

* **Question:** In a one-to-many relationship, the entity that is on the one side of the relationship is called a ________ entity in DBMS.
* **Options:**
* **parent** (Correct)
* child
* instance
* subtype


* **Solution Description:** In a one-to-many relationship, the entity that is on the one side of the relationship is called a parent entity in DBMS.

---

### **2. Join Operations**

* **Question:** Which of the join operations do not preserve non-matched tuples in DBMS?
* **Options:**
* Left outer join
* Right outer join
* **Inner join** (Correct)
* Natural join


* **Solution Description:** INNER JOIN: Returns all rows when there is at least one match in BOTH tables.

---

### **3. Null Meaning**

* **Question:** In DBMS, a null value of an attribute indicates which of the following:
* **Options:**
* Zero
* Infinite
* Error
* **Unknown** (Correct)


* **Solution Description:** NULL value implies that the value for that particular attribute is unknown, this is not same as 0 or error.

---

### **4. DBMS Basics**

* **Question:** Which of the following is true:
* **Options:**
* Relation and table are same
* Attribute is column in table
* None of the above
* **A and B both** (Correct)


* **Solution Description:** For design purpose, table and relation means the same. Although, technically a relation does not have duplicate value but a table can contain duplicate. Similarly, the attributes and the column are the same.
