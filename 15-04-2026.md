## **Problem 1: Data Definition Language (DDL)**
**Problem Statement:** Which is a DDL command in SQL?

* [ ] SELECT
* [ ] UPDATE
* [ ] DELETE
* [x] **CREATE**

**Solution Description:**
`CREATE` is a DDL command used to create tables or databases.

## **Problem 2: ER Diagram**
**Problem Statement:** ER diagram represents which of the following data models:

* [x] **Conceptual**
* [ ] Physical
* [ ] Logical
* [ ] Minimised

**Solution Description:**
ER diagram creation is part of the conceptual design process wherein we identify entities, relationships, attributes, types of entities, etc. They come under the category of conceptual data models.

## **Problem 3: Read Lock**
**Problem Statement:** Which of the following is the query to apply Read Lock on table **Employees** in DBMS?

* [x] **`LOCK TABLE Employees READ;`**
* [ ] `LOCK TABLE Employees READ|WRITE;`
* [ ] `LOCK TABLE Employees PRIORITY READ;`
* [ ] `LOCK TABLE Employees READ ONLY;`

**Solution Description:**
READ LOCK allows a user to only read the data from a table. The syntax for READ LOCK is `LOCK TABLES T_name READ`.

## **Problem 4: Set Operators**
**Problem Statement:** In precedence of set operators, the expression is evaluated from:

* [ ] Left to left
* [x] **Left to right**
* [ ] Right to left
* [ ] From user specification

**Solution Description:**
The expression is evaluated from left to right according to the precedence.

## **Problem 5: Exclusive Lock Usage**
**Problem Statement:** In which scenario would an exclusive lock (write lock) be necessary?

* [ ] When multiple transactions need to query the same data simultaneously.
* [x] **When a transaction needs to update the stock quantity of a product in an inventory system.**
* [ ] When a transaction needs to count the total number of rows in a table.
* [ ] When a transaction wants to read data without risking inconsistencies.

**Solution Description:**
An exclusive lock is essential during updates to ensure no other transaction can read or modify the data while changes are being made, preserving data integrity.
