### **1. SQL Alias**
**Problem Statement:** What does an alias do in SQL?

* **[Correct] Renames a column**
* Joins tables
* Sorts data
* Groups data

**Solution Description:** Alias temporarily renames a column or table.

### **2. Multi-level Indexing**
**Problem Statement:** Which of the following will be considered as multi-level indexing in Database?

* Clustering indexing
* **[Correct] Secondary indexing**
* Primary Indexing
* All of them

**Solution Description:** Secondary index is taken into consideration when the size of datafile increases i.e. when the size of the table increases, sparse indexing starts to slow down. To overcome this we introduce another level of indexing that is known as secondary indexing. In this, we select a huge chunk of columns initially and put it up at the first level of indexing which is known as primary level indexing. The data of primary level indexing is stored in primary memory. After this, each chunk is divided into smaller ranges. This is known as the second level of indexing, this is stored in the secondary memory along with the actual data file. Secondary indexing is also known as multilevel indexing.

### **3. Storage Issue**
**Problem Statement:** What does same data being saved in multiple locations called?

* Inconsistency
* **[Correct] Redundancy**
* Integrity
* Security

**Solution Description:** Repeating the same data at different locations is called the redundancy of data. In file-based systems, it is very difficult to keep track of redundancy.

### **4. Referential Integrity**
**Problem Statement:** Referential integrity constraint in DBMS states that foreign key should have a matching primary key or it must be not Null.

* True
* **[Correct] False**

**Solution Description:** False. Referential integrity in a DBMS ensures a foreign key either matches a primary key in the referenced table or is NULL (if permitted). The statement wrongly states the foreign key "must be not NULL".

### **5. ER Diagram**
**Problem Statement:** Which of the following is not true for ER Diagram in DBMS?

* ER Diagram is a visual representation for ER model
* ER diagrams has three components: entities, relationships and attributes
* **[Correct] ER diagram is not a high level data model diagram**
* All of the above

**Solution Description:** ER Diagram is a high level data model diagram, which helps in visualising and designing the database components.
